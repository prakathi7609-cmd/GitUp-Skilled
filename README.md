🚀 GitUp-Skilled

### AI-Powered RDD Portfolio Architect

## 💡 About the Project
GitUp-Skilled is an AI-powered platform that
helps students overcome Tutorial Hell by
connecting their skills with real-world
open-source GitHub projects.

## 🎯 Problem
Students often build repetitive projects
that fail to demonstrate real-world
development experience.

## 💻 Our Solution
Our platform analyzes resumes and job
descriptions to identify skill gaps and
recommend suitable open-source issues.

## ✨ Key Features

1. AI Resume Analyzer
2. Skill Gap Detection
3. GitHub Issue Finder
4. Personalized Learning Roadmap
5. Live Pull Request Tracker
6. AI Resume Upgrader

## 🛠️ Tech Stack

- Frontend: Next.js
- Backend: Python FastAPI
- AI: Google Gemini
- Database: Supabase
- API: GitHub Octokit

## 🌟 Our Mission

Bridging the gap between learning
and real-world software development.
